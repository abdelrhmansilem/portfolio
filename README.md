# 🛡️ Abdelrhman Salim — Portfolio

A personal portfolio landing page for **Abdelrhman Salim** — CyberSecurity & Software Engineering student at Suez Canal University, and Bug Bounty Hunter on HackerOne, Bugcrowd & private programs.

> Live styles: calm off-white & emerald theme with an animated particle-network background. 🌙 Dark/light mode included.

## ✨ Features

- **Animated background** — canvas particle network (mouse-reactive) + soft aurora orbs, built with vanilla JS (no libraries)
- **Dark / Light mode** — toggle button, saved in `localStorage`, follows OS preference by default
- **Fully responsive** — optimized for mobile, tablet & desktop with a hamburger menu
- **Profile photos** — banner + auto-cropped headshot
- **Official icons** — local SVG/ICO assets for languages (C++, Java, JS, Python, Bash, C), platforms (TryHackMe, PortSwigger, HackTheBox, ICPC) and socials (LinkedIn, X, GitHub, Medium)
- **Zero dependencies** — pure HTML, CSS & vanilla JS; works offline

## 📂 Structure

```
portfolio/

├── favicon.svg/.png    # Site icons

```
