# Reverse Engineering

Taking shipped binaries apart — Android first, native code where the answer lives there.

📱

Android APK reverse engineering

jadx and apktool against a production game client: 10,385 classes, 6,721 DEX files and 10,859 resources mapped, then swept for credentials and internal endpoints.

🧩

Native binary analysis

Ghidra headless analysis and decompilation on a 493 MB Unreal libUnreal.so, with symbol and property sweeps for engine configuration and credential material.

⚙️

Runtime instrumentation

Frida on a physical device to dump live configuration and observe API traffic where static analysis dead-ends.

🔐

Signing & provenance

APK Signing Block parsing for v2/v3 certificates, so a build is proven vendor-signed before it is trusted, plus pinning checks against intercepted traffic.

🔎

Secret triage

121 base64 literals decoded and leaked API keys validated with read-only oracles — a key that unlocks nothing is dropped instead of reported.

🧰

Toolchain

adb · apktool · uber-apk-signer · jadx · Ghidra · Frida · Python for the glue that ties them together.
